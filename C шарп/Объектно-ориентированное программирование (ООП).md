#### Основные принципы ООП

Объектно-ориентированное программирование позволяет моделировать реальный мир в коде. Сущности представляются в виде объектов, у которых есть характеристики (данные) и поведение (функции). Если описывается автомобиль, у него есть характеристики (цвет, марка, год выпуска, текущая скорость) и поведение (завести двигатель, разогнаться, затормозить, сигналить).

Класс — это шаблон, по которому создаются объекты. В нём задаются общие характеристики и действия для всех объектов этого типа. Объект — конкретный экземпляр класса. Например, есть класс Car, а объекты — это «Toyota», «BMW». Свойства (атрибуты) — характеристики объекта (цвет, мощность двигателя, объём бака). Методы — действия, которые объект может выполнять («завестись», «поехать», «остановиться»).

#### Принципы ООП

1. Абстракция. Выделение главных, существенных характеристик объекта и игнорирование второстепенных. Абстракция представляет сложную систему в виде набора простых моделей. Определяется, что объект делает, скрывая то, как он это делает. Пример: при вождении автомобиля видны руль, педали и приборная панель. Не нужно знать, как работает двигатель внутреннего сгорания или коробка передач, чтобы повернуть налево.

2. Инкапсуляция. Сокрытие внутреннего состояния объекта от прямого доступа извне. Доступ к данным и методам осуществляется через специально определенные интерфейсы. Данные и методы объединяются в одном объекте, что защищает данные от некорректного внешнего использования. Пример: смартфон. Напрямую изменить напряжение на процессоре нельзя. Взаимодействие идет через кнопки, сенсорный экран и разъемы (публичный интерфейс). Внутренняя «начинка» (приватные поля и методы) скрыта.

3. Наследование. Механизм создания нового класса на основе существующего. Новый класс (производный, дочерний) получает поля и методы родительского класса, может дополнять их или переопределять. Это позволяет переиспользовать код и выстраивать иерархии. Пример: класс Транспорт имеет методы двигаться() и сигналить(). Класс Автомобиль наследует их, добавляя открыть_дверь(). Класс Поезд наследует двигаться(), но переопределяет его (едет по рельсам).

4. Полиморфизм. Способность объектов с одинаковым интерфейсом иметь разную реализацию. Позволяет обращаться с объектами разных классов единообразно, если они наследуют общий класс или реализуют общий интерфейс. «Один интерфейс — множество реализаций». Пример: функция заставить_звучать(животное) вызывает метод издать_звук(). Для объекта Собака она выведет «Гавкнет», для Кошка — «Мяукнет», для Корова — «Му-у-у». Код функции не меняется.

#### Перегрузка методов

Возможность объявлять в одном классе несколько методов с одинаковым именем, но разными параметрами (типом, количеством или порядком).

Пример с разными параметрами в классе калькулятора:

```csharp
public class Calculator
{
    public int Add(int a, int b)
    {
        return a + b;
    }
    public int Add(int a, int b, int c)
    {
        return a + b + c;
    }
    public double Add(double a, double b)
    {
        return a + b;
    }
    public string Add(string a, string b)
    {
        return a + b;
    }
}
```

Перегрузка по типам параметров (класс принтера):

```csharp
public class Printer
{
    public void Print(int number) { Console.WriteLine($"Int: {number}"); }
    public void Print(string text) { Console.WriteLine($"String: {text}"); }
    public void Print(double number) { Console.WriteLine($"Double: {number}"); }
    public void Print(object obj) { Console.WriteLine($"Object: {obj}"); }
}
```

Перегрузка по количеству параметров (класс логгера):

```csharp
public class Logger
{
    public void Log(string message) { Console.WriteLine(message); }
    public void Log(string message, string level) { Console.WriteLine($"{level} {message}"); }
    public void Log(string message, string level, DateTime timestamp) { Console.WriteLine($"{timestamp} {level} {message}"); }
}
```

Преимущества перегрузки: удобство API (один интуитивно понятный метод для схожих операций); гибкость (передача разного количества и типов параметров); обратная совместимость (добавление новых перегрузок не ломает существующий код); читаемость (код структурирован).

#### Операции класса

Класс — это шаблон, схематическое описание построения объекта. Физическое представление в оперативной памяти класс получает только после создания объекта. Класс хранит характеристики и методы. В классе Person есть поля (ФИО, возраст, пол) и команды (спать(), идти гулять()).

Создание класса:

```csharp
class Person
{
    public string name = "";
    public int age;
    public string male = "";

    public void SayHello()
    {
        Console.WriteLine($"Привет, меня зовут {name}");
    }
}
```

В .NET четыре модификатора доступа. public – доступен всем. protected – доступен только самому объекту и его потомкам. private – закрытый, не доступен за пределами класса и для потомков. Используется по умолчанию, если модификатор не указан. internal – доступен только в пределах текущей сборки.

Создание и удаление объектов. Для работы нужно объявить переменную типа класса и проинициализировать её через new.

```csharp
Person person = new Person();
person.name = "Test";
person.age = 5;
person.male = "м";

Person person = new Person()
{
    name = "Test",
    age = 5,
    male = "м"
};
```

Память выделяется динамически. В C++ её освобождает программист через delete. В C# память освобождает Сборщик мусора, который запускается без вмешательства программиста. Его функции: обнаружение недоступных объектов (на которые нет ссылок) и освобождение их памяти.

Свойства. Поля по умолчанию частные (private). Публичные поля можно читать и менять где угодно. Чтобы контролировать доступ, используют свойства. Свойство состоит из имени и аксессоров get (чтение) и set (запись). В set используется ключевое слово value, передающее значение. Если есть только get, изменение запрещено. Если только set, чтение невозможно. Имена полей пишутся со строчной буквы, свойства — с прописной.

```csharp
class Person
{
    string name;
    int age;
    decimal amount;

    public string Name
    {
        get { return name; }
        set { if (name == null) name = value; }
    }
    public int Age
    {
        get { return age; }
        set { if (age == 0) age = value; }
    }
    public decimal Amount
    {
        get { return amount; }
        set { amount = value; }
    }
    public Person() { amount = 0; }
    public void Info() { Console.WriteLine($"Имя {name}\nВозраст {age}\nДеньги {amount}"); }
}
```

Конструкторы. Инициализировать поля можно при создании, через присваивание или через метод Initialize. Метод Initialize нужно вызывать после создания объекта, что неудобно. Конструктор инициализирует объект при его создании. Имя совпадает с именем класса, он не возвращает значение, тип возвращаемого значения не указывается. Вызывается по умолчанию в момент создания объекта. Обычно используется public. Для ссылки на текущий объект используется this, чтобы различить поля и параметры с одинаковыми именами.

```csharp
class Person
{
    public string name = "";
    public int age;
    public string male = "";

    public Person(string name, int age, string male)
    {
        this.name = name;
        this.age = age;
        this.male = male;
    }
}
```

#### Статичность

Ключевое слово static относится к методам и переменным. Обычные методы требуют создания объекта. Статические методы и переменные прикрепляются к классу, а не к объекту. К ним можно обращаться без создания экземпляра. Метод Main() вызывается без создания класса благодаря static. Статический метод может использовать только локальные переменные или внешние статические переменные. При создании новых объектов память для статических переменных не выделяется. Существует только одна версия статической переменной для всех объектов. Пример: подсчет количества созданных объектов.

```csharp
class Person
{
    static int ObjectNumber = 0;
    public int getObjectNumber() { return ObjectNumber; }
    public Person() { ObjectNumber++; }
}
```

#### Создание множества экземпляров

Через массив (фиксированный размер):

```csharp
Person[] person = new Person[2];
for (int i = 0; i < person.Length; i++)
{
    person[i] = new Person(Console.ReadLine(), int.Parse(Console.ReadLine()), Console.ReadLine());
}
```

Через список (динамический массив, решает проблемы масштабируемости):

```csharp
List<Person> Persons = new List<Person>();
Persons.Add(new Person("Данил Колбасенко", 5, "Мальчик"));
Persons.Add(new Person("Шалаши", 67, "Шалаш"));
Persons.Add(new Person("Иван", 5, "да"));

Persons.Remove(Persons[0]); 
Persons.RemoveAt(1); 
Persons.Insert(0, new Person("Марина", 5, "нет")); 
```

#### Перегрузка операторов

Позволяет работать с объектами классов, используя операторы (+, -, *, /, >, <), как с простыми типами.

```csharp
class MyPoint
{
    public int X { get; set; }
    public int Y { get; set; }
    public MyPoint(int x, int y) { X = x; Y = y; }

    public static MyPoint operator +(MyPoint a, MyPoint b)
    {
        return new MyPoint(a.X + b.X, a.Y + b.Y);
    }
    public static bool operator >(MyPoint a, MyPoint b) { return a.X > b.X && a.Y > b.Y; }
    public static bool operator <(MyPoint a, MyPoint b) { return a.X < b.X && a.Y < b.Y; }
}
```

Операторы приведения. Явное преобразование (explicit):

```csharp
public static explicit operator MyPoint(Person person)
{
    return new MyPoint(person.X, person.Y);
}
```

Неявное преобразование (implicit):

```csharp
public static implicit operator MyPoint(Person person)
{
    return new MyPoint(person.X, person.Y);
}
```

#### Шаблоны

Спасают от написания одинакового кода для разных типов данных. Тип object небезопасен. Шаблоны решают эту проблему.

```csharp
static string summ<T>(T value1, T value2)
{
    return value1.ToString() + value2.ToString();
}

public class TemplateTest<T>
{
    T[] array = new T[10];
    int index;
    public bool Add(T value)
    {
        if (index >= 10) return false;
        array[index++] = value;
        return true;
    }
    public T Get(int index)
    {
        if (index < this.index && index >= 10) return array[index];
        return default(T);
    }
    public int Count() => index;
}
```

#### Наследование

Создание общего класса для множества других. Избегает дублирования кода. Отношения «родитель-потомок». Родитель — базовый класс, потомок — производный. Базовый класс создается, когда несколько классов используют одинаковые поля и методы. Производный класс наследует их, расширяет функционал и остается независимым. В описании производного класса после имени ставится двоеточие и имя базового класса. Унаследованные члены не нужно переописывать.

```csharp
class Base
{
    public int code;
    public void show() { Console.WriteLine($"Поле code: {code}"); }
}

class MyClass : Base
{
    public char symb;
    public void display()
    {
        Console.WriteLine($"Поле symb: {symb}");
        show(); 
    }
    public int Code { get { return code; } set { code = value; } }
}
```

Уровни доступа: public (везде), private (внутри класса), protected (внутри класса и у потомков, наследуется), internal (в пределах сборки). Если модификатор не указан — это private.

Конструктор производного класса вызывает конструктор базового через base:

```csharp
public Конструктор (аргументы) : base(аргументы)
{
}
```

#### Полиморфизм

Переопределение метода в производных классах. Если объявить Animal animal = new Cat(); и вызвать метод Hello(), сработает метод базового класса Animal, так как объект объявлен как Animal. Для решения проблемы используется virtual в базовом классе и override в производном. Решение о вызове метода принимается динамически во время выполнения программы.

```csharp
class Animal
{
    string name;
    public virtual void Hello() { Console.WriteLine($"{name} издает звук"); }
}
class Cat : Animal
{
    public override void Hello() { Console.WriteLine("Мяу"); }
}
```

#### Абстрактные классы

Класс, от которого нельзя создать объект. Определяет общий функционал для родственных объектов. Используется для больших функциональных единиц с базовым функционалом. Если нужно изменить базовый функционал во всех наследниках, это делается в одном месте. Может содержать обычные поля, свойства, конструкторы и методы с реализацией.

```csharp
public abstract class Vehicle
{
    public abstract void Move();
}
public class Car : Vehicle
{
    public override void Move() { Console.WriteLine("Машина едет"); }
}
```

#### Интерфейсы

Объявление, схожее с классом, но без реализации методов (все методы абстрактны). Описывает, какими функциями должен обладать класс. Нет модификаторов доступа, все методы считаются открытыми. Необходимо реализовать все поля и методы интерфейса в наследуемом классе. Используются для групп разрозненных объектов, которые могут быть не связаны между собой, или для проектирования небольшого функционального типа.

```csharp
public interface IAnimal
{
    void MakeSound();
    string Name { get; set; }
}

public class Dog : IAnimal
{
    public string Name { get; set; }
    public Dog(string name) { Name = name; }
    public void MakeSound() { Console.WriteLine($"{Name} говорит: Гав!"); }
}
```

#### Структуры

Набор типов данных под одним именем. Может работать как простой тип (без инициализации). Похожа на класс: есть модификаторы доступа, конструктор, поля, методы, свойства.

```csharp
struct Person
{
    public Person(string firstName, string lastName)
    {
        FirstName = firstName;
        LastName = lastName;
        age = 18;
    }
    public string FirstName;
    public string LastName;
    public int age;
    public void Print() { Console.WriteLine($"First Name {FirstName}\nLast Name {LastName}\nAge {age}"); }
}
```

Можно объявить без new и использовать как простую переменную:

```csharp
Person p;
p.FirstName = "Михаил";
Console.WriteLine(p.FirstName);
```

Если не выделять память через new, конструктор не вызывается, все поля равны нулю. Поля можно использовать только после явного присвоения значения. Если попытаться вывести неинициализированное поле (например, p.LastName), среда разработки сообщит об ошибке «Возможно использование не назначенного поля». Инициализация происходит только для конкретного поля.

Если инициализировать через new, все переменные будут проинициализированы значениями по умолчанию, ошибки не будет:

```csharp
Person p = new Person();
Console.WriteLine(p.LastName); 
```

Инициализация через конструктор:

```csharp
Person p = new Person("Михаил", "Александрович");
Console.WriteLine("Фамилия " + p.LastName);
```

Главное отличие структур от классов — место выделения памяти. Для простых данных память выделяется в стеке (размер известен). Для динамических данных (классы, массивы) — в куче. Память для структур выделяется в стеке. При использовании структуры как объекта требуется упаковка и распаковка (лишние действия процессора). С точки зрения управления памятью структуры лучше: стек освобождается эффективнее и не требует затрат на сборщик мусора. Если данные используются методами, требующими объект, выгоднее использовать класс.
