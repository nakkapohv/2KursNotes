#### СЛАУ

**СЛАУ** (система линейных алгебраических уравнений) - совокупность n-уравнений с n-неизвестными, в которой каждая переменная входит только в первой степени и отсутствуют произведения переменных. 
![[Pasted image 20261006130541.png]]
#### Матричная запись СЛАУ

Правило умножения матрицы на вектор.

Элемент i строки результата, равен скалярному произведению i строки матрицы a на вектор x
#### Расширенная матрица

**Расширенная матрица** — это краткая запись системы линейных алгебраических уравнений (СЛАУ), которая состоит из коэффициентов при неизвестных и добавленного справа столбца свободных членов
#### Количество решений СЛАУ

Три исхода:

Система имеет единственное решение
Система имеет бесконечно много решений 
Вообще не имеет решений 
#### Определитель и обратная матрица

Определитель (детерминант) квадратной матрицы — это числовая величина, которая вычисляется по элементам матрицы и характеризует её свойства.

Обратная матрица существует только тогда, когда определитель не равен 0 

Главное в методе Гаусса — это последовательное исключение неизвестных.
![[Pasted image 20261006130635.png]]
#### Треугольная система и обратный ход

Треугольная система в методе Гаусса — это вид системы линейных алгебраических уравнений (СЛАУ), в которой матрица коэффициентов приведена к треугольному (или ступенчатому) виду, где все элементы ниже главной диагонали равны нулю

![[Pasted image 20261006115228.png]]
Простыми словами - это система, где первое уравнение содержит все неизвестные, второе все кроме x1, а третье только x3.
Обратный ход - это когда мы идём снизу вверх вычисляя, последовательно вычисляем, начиная с x3.
### Выбор ведущего элемента

Если ведущий элемент равен нулю, необходимо поменять текущую строку местами с другой строкой, в которой элемент в этом столбце не равен нулю.
Ведущий элемент - элемент, относительно которого выполняется исключение неизвестной на текущем шаге метода Гаусса.
![[Pasted image 20261006131759.png]]
#### Итерационные методы решения СЛАУ

Выражаем каждое неизвестное через остальные и подставляем значения по кругу, постепенно уточняя решение

**Метод Зейделя:** как только новое значение неизвестной найдено, оно **сразу используется** при вычислении следующей неизвестной. Метод Зейделя **сходится не всегда**. Для гарантированной сходимости нужны определённые условия, например, матрица системы может быть **строго диагонально преобладающей** (a при нужном нам x должен быть больше, чем b + c) или симметричной положительно определённой
