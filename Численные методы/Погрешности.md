
#### Классификация погрешностей 

Числовые методы - раздел вычислительной математики, который используется для приближенного решения некоторых математических задач, которые либо не имеют решения, либо оно очень сложные.

Итерационность - решаем задачи последовательно, ответ приближается к истинной цели.

Приближённость - представляем число в приближенном вид.

Приближенное число - это число, несильно отличающееся от исходного и заменяющее его в выражениях.

Погрешностью приближения - называется разница между точным и приближенным значением и оно может принимать, как положительное, так и отрицательное значение.

x - точное число
$x^*$ - приближенное число 
$x \approx x^*$ 
$3,14 \approx П$ 

#### Источники погрешности

1) Математическая модель - идеализированное представление сущности, которая выделяет основные черты и отбрасывает второстепенные черты или свойства.
2) Погрешность исходных данных - составляющая погрешности, обусловленная не точностью числовых данных, входящих в математическое описание задачи.
3) Совокупность погрешности математической модели и погрешности исходных данных, образуют неустранимую погрешность. 
4) Погрешность метода - составляющая погрешности, обусловленная заменой исходной математической задачи, другой задачей, которая точно решается данным численным методом.
5) Погрешность математичкой модели -  это ошибка, которая возникает, потому что модель это всегда упрощение реальной жизни. Она не описывает всё до мельчайших деталей, а лишь пытается уловить главные закономерности.
6) Вычислительная погрешность (погрешность округлений) - составляющая погрешности, обусловленная необходимостью выполнять арифметические операции над числами, усеченными до кол-ва разрядов, зависящего от применяемой вычислительной техники. 
7) Полная погрешность Δ(полная) = Δ(неустранимая)+ Δ(метода) + Δ(вычислительной)
	Δ - это погрешность

#### Классификация погрешностей 
###### Абсолютная и относительная погрешность

Абсолютной погрешностью приближенного значения - называют величину Δ, про которую известно что:

|x - $x^*$| ≤ Δ, где

Δ - абсолютная погрешность
$x^*$ - приближенное значение
x - точное число

Абсолютная погрешность предела:

$x^*$ - Δ(предела) ≤ x  ≤ $x^*$ + Δ(предела), например:

$x^*$ = 1,83м
Δ(предела) = 0,2м
x ∈ [ 1,63 ; 2,03 ]

По другому ещё записывают:

x = $x^*$ +- Δ(предела)

Относительной погрешностью приближенного значения, называют величину: δ, про которую известно:

$\delta = \frac{\Delta}{|x|}$ , где
x ≠ 0
δ * 100%

Если пользуемся приближенным значение то 

$\delta \approx \frac{\Delta}{|x^*|}$

Предельная относительная погрешность:

δ(предельная) = Δ(предельная)/ |$x^*$|

Δ = δ * |x|

#### Значащие и верные числа

Значащие цифры числа - называют все цифры в его десятичной записи, начиная с первой не нулевой слева
Значащую называют верной, если абсолютная погрешность числа не превосходит половины единицы разряда, соответствующего данной цифре.
Если все значащие верные, то всё записано верно

#### Погрешности простейших арифметических действий

Погрешность арифметического действия - называется, погрешность результата, обусловленная погрешностью операндов 
При сложении и вычитании, абсолютная погрешность складывается

Сложение и вычитание:
$x^*$ + $x^*$ 
Δ(общая) = Δ(1) + Δ(2) 
δ(общая) = Δ(1) + Δ(2)/x(1)+-(x2)

Умножение и деление:

δ $x^*$ * $x^*$ (и при $x^*$ / $x^*$ ) = δx(1) + δx(2)
Δ x(1) * x(2) = |x(1)*x(2)| * (Δ(1) + Δ(2))
Δ x(1) / x(2) = |x(1) / x(2)| * (Δ(1) + Δ(2))

Возведение в степень и корень:
