#### Просмотр документа

#### В Microsoft Word есть несколько режимов просмотра документа:

- Разметка страницы — показывает документ в виде страниц
- Режим чтения — используется для чтения документа
- Веб-документ — показывает текст как веб-страницу
- Черновик — используется при редактировании текста

Также можно менять масштаб просмотра. Масштаб меняет только отображение документа на экране.
#### Перемещение по документу

Для перемещения можно использовать мышь, полосу прокрутки и клавиатуру. Основные клавиши:

- Home — начало строки.
- End — конец строки.
- Page Up — вверх на один экран.
- Page Down — вниз на один экран.
- Ctrl + Home — начало документа.
- Ctrl + End — конец документа.

Для перехода к определённой странице можно использовать команду Перейти.
#### Закладки

Закладка — это метка в определённом месте документа. Она нужна для того, чтобы потом быстро перейти к этому месту.

Создание закладки:

- Поставить курсор в нужное место
- Открыть Вставка и потом Закладка
- Ввести имя
- Нажать Добавить
- После этого можно открыть список закладок и перейти к нужной

#### Гиперссылки

Гиперссылка — ссылка, по которой можно перейти в другое место. Гиперссылка может вести:

- на сайт
- на файл
- на электронную почту
- на другое место в документе

Создание гиперссылки:

- Выделить текст.
- Выбрать Вставка и потом ссылка
- Указать место перехода
- Подтвердить
#### Оформление текста

При оформлении документа можно менять:

- шрифт
- размер шрифта
- начертание
- выравнивание
- отступы
- интервалы между строками
- интервалы между абзацами

Для оформления заголовков и текста используются стили. Основные стили:

- Обычный — основной текст
- Заголовок 1 — основной раздел
- Заголовок 2 — подраздел
- Заголовок 3 — раздел внутри подраздела
#### Титульный лист

Титульный лист — это самая первая страница. На нём обычно указывают:

- учебное заведение или заведение работы
- название самой работы
- вид работы
- ФИО студента/сотрудника
- группу
- ФИО преподавателя/руководителя
- город
- год
#### Список литературы

Список литературы содержит источники, которые использовались при выполнении работы. В список могут входить:

- книги
- учебники
- статьи
- сайты
- электронные документы

Для источника указывают автора, название и другие данные в зависимости от типа источника. Список литературы располагается в конце работы.
#### Страницы

У страницы можно изменить:

- размер бумаги
- ориентацию
- поля
- колонтитулы
- нумерацию

Ориентация страницы бывает:

- книжная
- альбомная

#### Разрыв страницы

Разрыв страницы начинает текст с новой страницы. Используется, когда новый раздел должен начинаться с новой страницы.

Создание:

- Вставка и потом разрыв страницы
- Разрыв страницы лучше использовать вместо большого количества нажатий Enter.

#### Разделы документа

Раздел — часть документа со своими настройками страницы. Для разных разделов можно задать:

- другую ориентацию
- другие поля
- свои колонтитулы
- другую нумерацию
- другое количество колонок
#### Нумерация страниц

Нумерация страниц добавляет номера к страницам документа. Создание нумерации страниц:

- Вставка и потом Номер страницы

Номер можно расположить:

- сверху страницы
- снизу страницы
- на полях

При изменении количества страниц нумерация изменяется автоматически.
#### Колончатый текст

Колонки — способ расположения текста в несколько вертикальных частей. Создание колонок:

- Макет → Колонки

Можно выбрать:

- одну колонку
- две колонки
- три колонки
- другие параметры

Также можно изменить ширину колонок и расстояние между ними.

#### Внесение исправлений

При редактировании документа можно:

- добавлять текст
- удалять текст
- заменять слова
- копировать текст
- перемещать текст
- искать нужные слова
- заменять слова через поиск

Функция Исправления показывает изменения, которые были внесены в документ. Можно увидеть:

- добавленный текст
- удалённый текст
- изменения форматирования

Исправления можно принять или отклонить.

#### Примечания

Примечание — комментарий к определённому месту документа. Примечания используются, чтобы оставить замечание или пояснение.

#### Составные документы

Составной документ состоит из нескольких разных элементов. В него могут входить:

- текст
- таблицы
- рисунки
- диаграммы
- ссылки
- другие объекты

Разные части документа можно объединять в одном файле.

#### Слияние документов

Слияние документов используется для создания нескольких документов на основе одного шаблона. Например, можно сделать несколько писем с разными именами получателей. При слиянии используются:

- основной документ — общий текст
- источник данных — имена, адреса и другие данные
#### Колонтитулы

Колонтитул — область в верхней или нижней части страницы.В колонтитуле можно разместить:

- номер страницы
- название документа
- название раздела
- дату
- имя автора

Бывают:

- верхний колонтитул;
- нижний колонтитул.

Колонтитул может отображаться на нескольких страницах.

#### Сноски

Сноска — дополнительная информация, связанная с текстом. Сноска обычно обозначается номером в тексте, а её содержание находится внизу страницы. Создание сноски:

- Ссылки и потом вставить сноску

#### Оглавление

Оглавление — список разделов документа с номерами страниц. Для автоматического создания оглавления сначала нужно применить к заголовкам стили:

- Заголовок 1
- Заголовок 2
- Заголовок 3

После этого:

- Ссылки потом оглавление, и потом автоматическое оглавление

Если в документе что-то изменилось, оглавление можно обновить.
