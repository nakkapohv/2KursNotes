#### Работа с рисунками в документе

В LibreOffice Writer можно добавлять в документ рисунки, фотографии, схемы и другие изображения. Для вставки изображения используется меню Вставка - Изображение (можно вставить ctrl-v). После добавления рисунок можно изменять по размеру, перемещать по странице и поворачивать.
#### Вставка рисунков

После вставки изображения появляются дополнительные инструменты для его настройки. Можно изменить ширину и высоту, положение на странице, границы и другие параметры. Размер рисунка обычно меняется за угловые маркеры, чтобы сохранить его пропорции. Если нужно установить точные значения, можно открыть свойства изображения.
#### Составление блок-схемы

Блок-схему можно сделать с помощью фигур и соединительных линий. Для этого используются инструменты рисования LibreOffice. В блок-схеме обычно применяются:

- прямоугольник — действие или операция
- параллелограмм - операции ввода или вывода данных
- ромб — условие
- овал — начало или конец алгоритма
- стрелки и линии — направление выполнения
#### Переупорядочивание слоев рисунка и вращение фигур

Если в документе несколько объектов находятся друг на друге, можно изменить их порядок. Для этого используются команды:

- На передний план
- На задний план
- На передний план на один уровень 
- На задний план на один уровень.

Также фигуры можно вращать. Для этого выбирается объект, после чего используется команда поворота или специальные маркеры вокруг фигуры. Порядок слоев нужен, например, когда одна фигура должна находиться поверх другой.
#### Создание рисунка-подложки для текста

Рисунок можно использовать как фон или подложку для текста. Для этого изображение размещают за текстом и настраивают его положение. Такой вариант можно использовать, например, для оформления страницы, размещения водяного знака или текста поверх изображения.
#### Управление обтеканием рисунка текстом

Обтекание определяет, как текст будет располагаться относительно изображения. Настройка обтекания находится в свойствах изображения и позволяет нормально разместить рисунок внутри текста. Можно выбрать разные варианты:

1) Без обтекания - текст находится отдельно от рисунка;
2) Обтекание - текст располагается вокруг изображения;
3) Сквозное - текст может размещаться поверх или рядом с рисунком;
4) На задний план - рисунок находится за текстом;
5) На передний план - рисунок располагается поверх текста.
#### Работа с научными формулами

В LibreOffice Writer есть редактор формул LibreOffice Math. С его помощью можно создавать математические и научные формулы, которые сложно набрать обычным текстом. Можно вводить дроби, степени, корни, индексы, интегралы, суммы и другие математические обозначения. Для вставки формулы используется вставка - объект - формула. После этого открывается редактор, где формула создаётся с помощью специальных команд. Формулы можно редактировать после вставки, изменяя их отдельные элементы. Примеры:

Дробь - a over b
Степень - x^2 
Индекс - a_1
Квадратный корень - sqrt{x}
Сумма - sum from {i=1} to {n} i
Интеграл - int x dx
Формула корней квадратного уравнения - x = {-b +- sqrt{b^2 - 4ac}} over {2a}
#### Табличный процессор

LibreOffice Calc — табличный процессор, предназначенный для работы с электронными таблицами. В нём можно хранить данные в виде таблиц, выполнять расчёты, использовать формулы и функции, строить диаграммы и обрабатывать большие наборы данных. Документ Calc состоит из листов. На каждом листе есть строки и столбцы, а на их пересечении находятся ячейки. Каждая ячейка имеет свой адрес, например A1, B2 или D5. В ячейки можно вводить текст, числа, даты и формулы.
#### Создание книг

В Calc создаётся электронная книга, которая может содержать несколько листов. Листы можно добавлять, удалять, переименовывать и менять их порядок. Например, в одной книге можно сделать отдельные листы для сотрудников, товаров и расчётов.

Новая книга создаётся через Файл - Создать - Электронная таблица
#### Форматирование таблиц

Данные в Calc можно форматировать для более удобного просмотра. Форматирование изменяет внешний вид данных, но само значение в ячейке при этом может оставаться тем же. Можно изменять:

- Размер и шрифты
- Выравнивание текста
- Цвет текста и фона
- Границы ячеек
- Ширину столбцов и высоту строк
- Формат чисел, дат, процентов и валют
#### Специальные возможности Calc

Calc позволяет сортировать и фильтровать данные, использовать условное форматирование, строить диаграммы и выполнять различные расчёты. 
Сортировка используется для расположения данных в определённом порядке, например по имени или по числу.
Фильтр позволяет временно показывать только те строки, которые подходят под заданные условия.
Условное форматирование автоматически меняет оформление ячеек в зависимости от их значения. Например, оценки ниже определённого числа можно выделить отдельно. 
Так же можно заменить мышку - клавиатурой, есть полное управление с клавиатуры.
#### Формулы

Формула в Calc начинается со знака =. Она может содержать числа, адреса ячеек, арифметические операции и функции.

Арифметические операторы:

- Сложение - "+"
- Вычитание - "-"
- Умножение - "*"
- Деление - "/"
- Возведение в степень - "^"

Популярные функции:

- СУММ() - складывает числа из указанного диапазона. Например: =СУММ(A1:A10)
- СРЗНАЧ() - вычисляет среднее арифметическое. Например: =СРЗНАЧ(B1:B10)
- ЕСЛИ() - выполняет действие в зависимости от заданного условия. Например: =ЕСЛИ(A1>10;"Много";"Мало")
- МАКС() - находит наибольшее значение в диапазоне. Например: =МАКС(A1:A10)
- МИН() - находит наименьшее значение в диапазоне. Например: =МИН(A1:A10)
- СЧЁТ() - считает количество ячеек, содержащих числа. Например: =СЧЁТ(A1:A10)
#### Макросы

В LibreOffice можно использовать макросы для автоматизации повторяющихся действий. Макрос представляет собой последовательность команд, которые выполняются автоматически. Для создания макросов в LibreOffice обычно используется LibreOffice Basic. С его помощью можно написать небольшую программу, которая будет работать с данными и объектами документа. Макрос может автоматически заполнять таблицу, изменять формат ячеек или выполнять несколько действий подряд.

Макросы открываются через Сервис - Макросы

Формулы и макросы используются для разных задач. Формулы нужны в основном для расчётов непосредственно в ячейках. Макросы позволяют автоматизировать действия и управлять документом с помощью кода.
