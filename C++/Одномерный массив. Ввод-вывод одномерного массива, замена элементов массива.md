
Одномерный массив - это набор однотипных элементов, расположенных в памяти последовательно друг за другом и имеющих общее имя. Доступ к элементу осуществляется по индексу. В C++ нумерация индексов начинается с 0

Объявление массива:

const int N = 5;  
int a[N]; // без инициализации, в памяти мусор  
int b[5] = {1, 2, 3, 4, 5}; // полная инициализация  
int c[] = {10, 20, 30}; // размер выводится автоматически (3)  
int d[5] = {}; // все элементы равны нулю

Размер массива должен быть известен на этапе компиляции, то есть это константа или литерал, но не переменная.

Ввод массива выполняется поэлементно в цикле:

const int N = 5;  
int a[N];

for (int i = 0; i < N; i++) {  
cin >> a[i];  
}

Вывод массива тоже выполняется поэлементно:

for (int i = 0; i < N; i++) {  
cout << a[i] << " ";  
}

Замена элементов массива — это просто присваивание нового значения по индексу:

a[0] = 999; // заменить первый элемент  
a[N-1] = 0; // заменить последний  
a[i] = a[i] * 2; // удвоить i-й элемент

Обмен двух элементов делается через временную переменную или через функцию swap:

int temp = a[i];  
a[i] = a[j];  
a[j] = temp;

// или  
swap(a[i], a[j]);

Замена по условию, например все отрицательные на ноль:

for (int i = 0; i < N; i++) {  
if (a[i] < 0) a[i] = 0;  
}

Важно помнить: не проверяет границы массива автоматически. Обращение к a[N] при размере N — неопределённое поведение: программа может молча испортить данные или упасть. За границами должен следить программист.
