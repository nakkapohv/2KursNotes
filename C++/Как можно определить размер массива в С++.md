
Оператор sizeof возвращает размер в байтах. Чтобы получить количество элементов, нужно разделить размер всего массива на размер одного элемента:

int a[10];  
size_t size = sizeof(a) / sizeof(a[0]); // 10

Здесь sizeof(a) - 40 байт, sizeof(a[0]) - 4 байта, результат - 10 элементов

Ограничение: способ работает только для настоящего массива в той же области видимости. Если массив передан в функцию, он превращается в указатель, и sizeof вернёт размер указателя, а не массива:

void f(int arr[]) {  
// sizeof(arr) == размер указателя, а не массива  
}

std::size - возвращает сразу количество элементов:

#include <iterator>

int a[10];  
size_t size = std::size(a); // 10

Преимущество: если случайно передать указатель вместо массива, программа не скомпилируется. Ошибка ловится на этапе компиляции, а не в рантайме

Для двумерного массива:

int A[3][4];  
size_t total = sizeof(A) / sizeof(A[0][0]); // 12  
size_t rows = sizeof(A) / sizeof(A[0]); // 3  
size_t cols = sizeof(A[0]) / sizeof(A[0][0]); // 4

Для std::vector и std::array используется метод size():

std::vector<int> v = {1, 2, 3};  
v.size(); // 3

std::array<int, 5> arr;  
arr.size(); // 5

Про typeof: в стандартном C++ такого оператора нет. В GCC и Clang есть расширение typeof (или **typeof**), но оно возвращает тип выражения, а не размер. Аналог в стандарте — decltype, который тоже возвращает тип:

int a[10];  
decltype(a) b; // b имеет тип int[10]

Для получения размера правильно использовать sizeof или std::size
