
Цикл - это конструкция, которая повторяет блок кода (тело цикла), пока выполняется заданное условие. Циклы нужны для обработки массивов, повторяющихся вычислений, перебора вариантов.

Цикл с предусловием проверяет условие до выполнения тела. Если условие изначально ложно - тело не выполнится ни разу.

Цикл с постусловием проверяет условие после выполнения тела. Тело гарантированно выполнится хотя бы один раз.

В C++ есть три оператора цикла

Цикл while - с предусловием:

int i = 0;  
while (i < 5) {  
cout << i << " ";  
i++;  
}

Здесь важно менять переменную внутри тела, иначе получится бесконечный цикл.

Цикл do-while — с постусловием:

int j = 0;  
do {  
cout << j << " ";  
j++;  
} while (j < 5);

Обратите внимание на точку с запятой после while(...). Тело выполнится минимум один раз — удобно, например, для меню или повторного запроса ввода.

Цикл for — с параметром, удобен, когда число повторений известно:

for (int k = 0; k < 5; k++) {  
cout << k << " ";  
}

Порядок работы for: сначала выполняется инициализация (один раз), затем проверяется условие, затем выполняется тело, затем приращение, и снова проверка условия.

Управляющие операторы: break - досрочно выйти из цикла, continue - пропустить остаток текущей итерации и перейти к следующей.

Циклы можно вкладывать друг в друга. Внешний цикл выполняется несколько раз, для каждой его итерации внутренний цикл проходит полностью.

Типичные ошибки: бесконечный цикл (не меняется условие), точка с запятой сразу после while(...) или for(...) (пустое тело), ошибка «на единицу» при обходе массива (i <= n вместо i < n), do-while без точки с запятой в конце.
