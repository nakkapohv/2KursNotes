
Двумерный массив (матрица) - это массив, для доступа к элементу которого нужно указать два индекса: номер строки i и номер столбца j. Первый индекс - строка, второй - столбец. Оба начинаются с 0.

Объявление:

const int ROWS = 3, COLS = 4;  
int A [ROWS] [COLS]; // 3 строки, 4 столбца — всего 12 элементов

Инициализация:

int B[2][3] = {  
{1, 2, 3},  
{4, 5, 6}  
};

В памяти двумерный массив хранится по строкам: сначала все элементы первой строки, затем второй и так далее. Поэтому обход по строкам (внешний цикл по i, внутренний по j) работает быстрее, чем обход по столбцам.

Ввод двумерного массива выполняется вложенными циклами:

for (int i = 0; i < ROWS; i++) {  
for (int j = 0; j < COLS; j++) {  
cin >> A[i][j];  
}  
}

Вывод двумерного массива - тоже вложенными циклами, при этом после каждой строки матрицы нужен переход на новую строку:

for (int i = 0; i < ROWS; i++) {  
for (int j = 0; j < COLS; j++) {  
cout << A[i][j] << "\t";  
}  
cout << endl;  
}

Символ \t - табуляция, чтобы столбцы были ровными

При объявлении двумерного массива второе измерение (число столбцов) опускать нельзя — компилятор должен знать длину строки, чтобы правильно вычислять адрес элемента A[i][j]. Первое измерение (число строк) можно опустить, если массив сразу инициализируется.

При передаче двумерного массива в функцию нужно указывать размеры всех измерений, кроме первого.

Типичные ошибки: перепутать i и j (написать A[j][i] вместо A[i][j]), выйти за границы по столбцам (внутренний цикл идёт до ROWS вместо COLS), передать массив в функцию без указания размеров
