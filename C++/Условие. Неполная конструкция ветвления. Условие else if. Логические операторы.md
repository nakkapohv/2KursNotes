
Условие - это выражение, которое может быть истинным (true) или ложным (false). По результату условия программа выбирает, какой блок кода выполнить. На этом основано ветвление - одна из трёх базовых конструкций программирования

Операторы сравнения: == (равно), != (не равно), > (больше), < (меньше), >= (больше или равно), <= (меньше или равно). Важно не путать = (присваивание) и == (сравнение): if (x = 5) не сравнивает, а присваивает и всегда истинно

Неполная конструкция ветвления - это if без else:

if (условие) {  
// выполнится, только если условие истинно  
}

Если условие ложно, блок просто пропускается, никаких альтернативных действий не выполняется.

Полная конструкция - это if с else, где выполняется одна из двух веток.

Конструкция else if позволяет проверить несколько условий по очереди. Как только одно условие истинно — остальные пропускаются:

if (x > 0) {  
// положительное  
} else if (x == 0) {  
// ноль  
} else {  
// отрицательное  
}

Порядок условий важен: более специфичные условия нужно ставить раньше, иначе до них не дойдёт выполнение

Логические операторы нужны для составления сложных условий:

- && (И, AND) — истинно, только если оба операнда истинны.
- || (ИЛИ, OR) — истинно, если хотя бы один операнд истинен.
- ! (НЕ, NOT) — инвертирует значение.

Операторы работают по принципу короткого замыкания: в a && b, если a ложно, b не вычисляется; в a || b, если a истинно, b не вычисляется.

Частые ошибки: путать = и ==, забывать фигурные скобки, когда в ветке больше одной инструкции, сравнивать дробные числа через ==, неправильно расставлять порядок else if
