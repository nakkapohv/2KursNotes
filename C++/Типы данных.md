
Тип данных определяет, какие значения может хранить переменная, сколько памяти она занимает и какие операции с ней можно выполнять. В C++ типы делятся на несколько групп

Целочисленные типы: short (2 байта), int (4 байта), long, long long (8 байт), а также их беззнаковые версии unsigned (хранят только неотрицательные числа, но диапазон вдвое больше). Используются для счётчиков, индексов, целых чисел

Символьные типы: char - один символ (обычно 1 байт, кодировка ASCII), wchar_t - широкий символ для Unicode

Логический тип: bool - принимает только два значения: true или false

Типы с плавающей запятой (для дробных чисел): float (4 байта, около 7 значащих цифр), double (8 байт, около 15 цифр), long double (точность ещё выше). Дробные числа нельзя сравнивать через == из-за погрешности округления - сравнивают через модуль разности

Тип void - «пустой», означает отсутствие значения. Используется для функций, которые ничего не возвращают.

Составные типы: массивы (набор однотипных элементов), структуры (несколько полей разных типов), классы (структуры с методами), указатели (хранят адрес), ссылки (псевдоним переменной), перечисления enum (именованные константы)

Пользовательские типы - создаются программистом через struct, class, enum, union, typedef или using
