
Процесс - это экземпляр выполняемой программы, включающий в себя текущие значения счетчика команд, регистров и переменных. Это абстракция, которая позволяет одному физическому центральному процессору выполнять несколько задач (псевдопараллельно), создавая иллюзию наличия нескольких виртуальных процессоров.

Для упрощения работы с параллельными вычислениями используется концептуальная модель последовательных процессов. В многозадачной системе реальный процессор быстро переключается между процессами, выделяя каждому из них доли миллисекунд. При этом у каждого процесса есть свой логический счетчик команд, значение которого сохраняется в памяти при переключении на другой процесс.

Важно различать процесс и программу. 
- Программа - это пассивный набор инструкций (алгоритм), хранящийся на диске
- Процесс - это активное действие, включающее в себя саму программу, входные данные и текущее состояние выполнения.
Если одна и та же программа запущена дважды, операционная система создает два разных процесса, которые могут использовать общий код, но работают независимо друг от друга.

Создание процессов происходит в четырех основных случаях: при инициализации операционной системы, при выполнении работающим процессом системного вызова для создания нового процесса, по запросу пользователя и при инициации пакетного задания. 

Созданные при старте системы процессы могут быть высокоприоритетными (взаимодействующими с пользователем) или фоновыми (демонами), которые выполняют специфические функции, например, ожидают входящую почту или обслуживают веб-запросы, активируясь только при необходимости.
