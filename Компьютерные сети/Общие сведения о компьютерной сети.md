
Компьютерная сеть - это система объединяющая компьютеры и другие устройства (сервера, принтеры, маршрутизаторы) для обмена данными и ресурсами

Цель - удаленный доступ к разделяемым ресурсам (пользователи могут по сети получить данные с другого компьютера на расстояние)

![[Pasted image 20260923092806.png]]
##### Классификация компьютерных сетей

- По средне передачи данных (проводные и беспроводные)
- По скорости передачи данных (низкоскоростные, среднескоростные, высокоскоростные) 
  Низкоскоростные <100 Гигабит
  Среднескоростные 100-1000 Гигабит
  Высокоскоростные >1000 Гигабит
- По размеру охваченной территории (глобальные, региональные, локальные)
- По организации локальной сети (одноранговые и с выделенным сервером)

Трафик - объем передаваемых по сети данных. Различают входящий трафик данных, получаемых компьютером из сети, и исходящий трафик данных, отправляемых компьютером в сеть.  Измеряется в байтах

Скорость передачи данных - это фактическая скорость потока данных, прошедшего через сеть. Определяется как отношение объема переданных данных за промежуток времени на продолжительность этого промежутка. Базовая единица – бит/сек

##### Сетевые характеристики

Пропускная способность – максимально возможная скорость передачи данных по каналу связи. Зависит от качества и характеристики физической среды передачи данных и используемой технологии передачи данных
#### Топология сети

![[Pasted image 20260923093517.png]]

Топология сети – схема расположения и соединения сетевых устройств

От выбора топологии связей существенно зависят характеристики сети

Например, наличие между узлами нескольких путей повышает надежность сети и делает возможным распределение загрузки между отдельными каналами

#### Виды топологий

‒ Полносвязная
![[Pasted image 20260923093742.png]]

Всё между собой связано
Сложное обслуживание 
Сложность расширения: для добавления нового узла его нужно напрямую соединить со всеми существующими

‒ Ячеистая
![[Pasted image 20260923094003.png]]

Высокая отказоустойчивость: множество альтернативных маршрутов позволяет сети самовосстанавливаться при отказе отдельных каналов или узлов
Гибкость: узлы могут выступать не только конечными точками, но и маршрутизаторами для других устройств
Высокая стоимость реализации и обслуживания из-за большого количества связей
Сложность настройки и управления, особенно в крупных сетях

‒ Кольцевая
![[Pasted image 20260923094119.png]]

Упорядоченность передачи данных: отсутствие коллизий при использовании маркерного доступа
Относительная простота расширения: добавление нового узла обычно не требует изменения конфигурации других узлов
Низкая отказоустойчивость в одиночном кольце: выход из строя одного узла или обрыв кабеля приводит к разделению сети на два изолированных сегмента
Сложность диагностики: локализация неисправности требует специального оборудования
Задержка передачи данных: из-за последовательного прохождения через каждый узел время доставки увеличивается
	
‒ Звездообразная («звезда»)
![[Pasted image 20260923094447.png]]

Высокая отказоустойчивость: выход из строя одного узла или его кабеля не влияет на работу остальных
Простота поиска неисправностей: центральный узел позволяет быстро локализовать проблему
Лёгкость масштабирования: для добавления нового узла достаточно проложить дополнительный кабель от центра
Критическая зависимость от центрального узла: его отказ приводит к неработоспособности всей сети
Большой расход кабеля
Ограничение на количество узлов: оно определяется пропускной способностью центрального устройства
