
### Среды передачи данных и виды передачи данных

Среда передачи данных - это канал связи, который соединяет узлы сети. Она бывает:

- проводная - например, кабель
- беспроводная - передача по радиоканалу

Виды передачи данных:

- симплексная - данные передаются только в одну сторону;
- полудуплексная - данные передаются в обе стороны, но по очереди;
- полнодуплексная - данные передаются одновременно в обе стороны.

Например, две рации работают в полудуплексном режиме, а телефонная связь — в полнодуплексном.
### Понятие доступа к сети передачи данных, метод доступа и конфликт доступа

Если несколько устройств используют одну среду передачи, они могут одновременно попытаться отправить данные. В этом случае возникает конфликт (коллизия). Доступ к среде передачи данных - это процесс управления разрешением на передачу данных. Метод доступа — это набор правил, по которым компьютер отправляет и принимает данные по сетевому кабелю.
### Какие существуют стандартные методы доступа?

- Централизованные - управлением занимается один узел, например сервер
- Децентрализованные - доступом управляют сами абоненты сети

Децентрализованные методы, в свою очередь, бывают:

- Детерминированные - доступ предоставляется по чётким правилам;
- Случайные (вероятностные) - порядок доступа заранее не определён.

### Какие существуют группы методов доступа, основанных на временном разделении канала?

Выделяют две группы:

- Централизованные — всё управление доступом находится в одном узле. Плюс в том, что конфликтов нет, потому что центр даёт право передачи только одному абоненту.
- Децентрализованные — управление доступом выполняют сами абоненты сети по определённым протоколам. Они более устойчивы к отказам, но при этом возможны конфликты.
### Какие существуют методы управления доступом к общей среде?

Есть два основных метода:

- Конкурентный доступ — устройства конкурируют за использование общей среды. Одновременно передавать данные может только одно устройство. Если несколько устройств начинают передачу одновременно, специальный протокол определяет, что делать в такой ситуации.
- Управляемый доступ — каждое устройство получает своё время для использования среды и ждёт своей очереди.

Примеры управляемого доступа: Token Ring и ARCNET.
### В чём отличие методов доступа CSMA/CD и CSMA/CA?

CSMA/CD - метод с обнаружением конфликтов. Устройство прослушивает среду, начинает передачу, а если возникает конфликт, обнаруживает его. Повреждённые данные затем передаются повторно. Использовался в старых локальных сетях Ethernet.
CSMA/CA — метод с предотвращением конфликтов. Он используется в беспроводных локальных сетях. Устройство старается избежать конфликта, ожидая своей очереди для передачи, так как в беспроводной сети обнаружить столкновение может быть невозможно.

CSMA/CD — обнаруживает конфликт.  
CSMA/CA — предотвращает конфликт.
### Какие наиболее известные маркерные методы доступа используются для передачи данных по локальной сети?

- Маркерная шина — стандарт IEEE 802.4.
- Маркерное кольцо — стандарт IEEE 802.5.

### Что такое маркер и какой у него формат?

Маркер — это управляющая последовательность бит, которая передаётся по сети и используется для управления доступом к сети. Маркер состоит из трёх полей по одному байту:

- SD — начальный ограничитель (Start Delimiter);
- AC — управление доступом (Access Control);
- ED — конечный ограничитель (End Delimiter).

Поле AC содержит биты приоритета, бит маркера T, бит монитора M и резервные биты. В поле ED находятся признаки промежуточного кадра I и ошибки E.
